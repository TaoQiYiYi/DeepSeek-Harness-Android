# DeepSeek Harness v0.2.2-rc3

> 发布日期：2026-10-14 ｜ versionCode __VC__ ｜ 运行时 r8（覆盖安装无需重解压）｜ DSH 内核 0.2.1-alpha.2

## rc3 新增：安卓 UI 适配（手机 ≤720px 生效，桌面布局不受影响）

### 1. 对话页独立成页
- 打开会话后进入全屏对话页：侧栏完全隐藏，对话与输入区占满整个屏幕，不再被侧栏挤压。
- 对话页左上角新增「←」返回按钮，一键进入会话选择页；系统返回同样生效。
- 进入对话页时侧栏自动收起；会话进行中侧栏保持收起，不会被误展开。

### 2. 会话选择页独立成页
- 点左上角「打开侧边栏」进入全屏「会话选择页」：会话列表、新会话按钮、插件/自动化任务入口、设置全部整行铺满，接近原生应用的信息页。
- 在会话选择页：点任一会话直接进入全屏对话页；按系统返回则收起本页，回到下层页面（对话/插件/自动化/首页草稿），不会误退出程序。

### 3. 主页独立成页
- 首页不再显示左侧图标栏，内容（欢迎区、工作区、输入框）占满全屏。
- 左上角新增「会话列表」菜单键（☰），一键进入会话选择页；右上角保留分栏切换。

### 4. 插件 / 自动化任务页独立成页（build 43）
- 在会话选择页点「插件」「自动化任务」：直接全屏打开对应页面，会话列表自动收起，不再被列表盖住。
- 这两个页面不再显示左侧图标栏，内容全屏。
- 在这两个页面滑动返回：回到会话选择页，不再直接退出程序。

### 5. 顶栏标题对齐与截断修复（build 42 / 43）
- 对话页顶栏的会话名称与下方「对话 / 轨迹」选项卡左对齐（修复左侧 50px 缩进）。
- 会话名称不再被压缩成一两个字（如「插...」），长标题在窄屏尽可能完整显示。
- 「⋯」按钮贴紧最右侧分栏切换按钮，不再隔大段空白。

### 6. 返回键分级处理（build 37 ~ 43）
- 对话页：左上角「←」或系统返回 → 会话选择页；会话选择页再返回 → 回到下层页面。
- 插件 / 自动化页：系统返回 → 会话选择页。
- 弹窗 / 设置面板打开时：先关闭弹层。
- 只有确实无处可退时才退出应用。

### 7. 新会话「开始」页识别（build 42）
- 新会话的「开始」页（罗盘 + 工作区文件/新建终端卡片）按会话页处理：带返回键、系统返回可用，不再误判为主页。

### 8. 修复：设置页滑动返回直接退出程序（build 38）
- 原因：设置面板的「关闭」按钮文字无法被返回键处理逻辑识别，导致系统返回时误判为"无处可退"而退出应用。
- 现在：设置页（及各类弹窗）滑动返回 = 关闭面板，回到之前的页面。

### 9. 修复：版本号显示错误（build 44）
- 之前：设置面板「获取更新」条与「关于」弹窗显示的版本号停留在 0.2.2-rc2（内置常量自 build 36 后未跟随更新）。
- 现在：版本号改为运行时读取系统安装信息，界面显示、更新检查、「关于」三处永远与实际安装版本一致。

## 自 v0.2.2-rc2 继承（已包含在本包中）

- **「更多字体设置」展开区挤压修复**（build 35）：正文字体/代码字体/终端字体三行窄屏换行排布，文字宽度 95px → 359px。
- **第三方移动端适配插件兼容**（build 36，如 dsh-web-mobile）：插件接管时内置适配自动让位；新增页面渲染异常自动检测与「禁用插件重载」自救。

## 升级方式
1. 直接覆盖安装（签名一致，会话与配置全部保留）。
2. 运行时未变化（r8），覆盖安装无需重新解压，秒开。
3. 覆盖安装后桌面图标未刷新时，重启启动器或手机即可。
