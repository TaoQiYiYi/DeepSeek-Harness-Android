# 更新说明：v0.2.2-rc2 → v0.2.2-rc3

> 2026-10-14 ｜ build 36 → __VC__ ｜ 运行时 r8 不变（覆盖安装无需重解压、秒开）

rc3 是「安卓 UI 适配」专项：让官方 Web 界面在手机上真正像原生应用——每个页面独立全屏、返回键逐级可退。以下按反馈批次列出。

## 1. 对话页独立成页（build 37）
- 以前：打开会话后，左侧栏仍占着 320px，对话被挤在剩余空间里，输入区也很窄。
- 现在：进入会话即全屏对话页，侧栏隐藏；左上角「←」返回按钮一键进入会话选择页；会话进行中侧栏保持收起。

## 2. 会话选择页独立成页（build 37）
- 以前：点「打开侧边栏」弹出一个 320px 抽屉盖在页面上，列表挤在左窄条里。
- 现在：全屏会话选择页，会话列表 / 新会话按钮 / 插件 / 自动化任务 / 设置全部整行铺满。

## 3. 主页独立成页（build 38）
- 以前：首页左侧留着一竖条图标栏（新会话 / 插件 / 搜索 / 设置），内容被挤到右边。
- 现在：图标栏隐藏，内容全屏；左上角「☰」进入会话选择页。

## 4. 顶栏适配（build 38 / 42 / 43）
- 「⋯」按钮贴紧右栏切换按钮，不再隔着大段空白（build 38）。
- 会话名称不再被压缩成一两个字，长标题尽可能完整显示（build 42）。
- 标题与下方「对话 / 轨迹」选项卡左对齐，修复 50px 缩进（build 43）。

## 5. 修复：设置页滑动返回直接退出程序（build 38）
- 原因：设置面板「关闭」按钮的文字没有被返回键逻辑识别，误判"无处可退" → 退出应用。
- 现在：设置页滑动返回 = 关闭面板回到原页面。

## 6. 新会话「开始」页识别（build 42）
- 新会话的「开始」页（工作区文件 / 新建终端卡片）此前没有返回键、滑动返回会退出程序；现已按会话页处理。

## 7. 插件 / 自动化任务页独立成页 + 返回修复（build 43）
- 以前：点「插件」「自动化任务」后，会话列表仍盖在上面看不到页面；在这两个页面滑动返回会直接退出程序。
- 现在：页面直接全屏打开（列表自动收起、图标栏隐藏）；滑动返回回到会话选择页，绝不误退。

## 8. 返回键体系（build 37 ~ 43）
- 会话选择页：返回 → 收起，回到下层页面（对话 / 插件 / 自动化 / 首页草稿），不退出程序。
- 对话页：返回 → 会话选择页；再返回 → 下层页面。
- 插件 / 自动化页：返回 → 会话选择页。
- 弹窗 / 设置面板打开时：先关弹层。
- 只有确实无处可退时才退出应用。

## 9. 修复：版本号显示错误（build 44）
- 之前：设置面板「获取更新」条与「关于」弹窗显示的版本号停留在 0.2.2-rc2（内置常量自 build 36 后未跟随更新）。
- 现在：版本号改为运行时读取系统安装信息，与实际安装的 APK 版本永远一致（界面显示、更新检查、关于弹窗三处）。

## 升级
- 覆盖安装 `__APK__` 即可，会话与配置全部保留。
- SHA-256：`__SHA__`
